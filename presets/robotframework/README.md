# presets/robotframework

Scaffold for devenv `languages.robotframework` tool presets.

- Attrpaths: `robotframework.*` (for example `robotframework.lint.<tool>`)
- Category policy inherits when `languages.robotframework.enable` (or category override)
- Add preset modules as `*.nix` (names must not start with `_`). Helpers may use `_*.nix`.
